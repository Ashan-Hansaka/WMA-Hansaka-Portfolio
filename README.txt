## How to run

1. Put your profile photo in `images/profile.jpg`.
2. Put your project screenshots in:
   - `images/project1.jpg`
   - `images/project2.jpg`
   - `images/project3.jpg`
3. Put your CV PDF in the main folder and name it `CV.pdf`.
4. Open `index.html` in Google Chrome.

## Important

Replace the placeholder email, LinkedIn, GitHub, education, project and experience details with your real information.

The website uses:
- HTML5
- CSS3
- JavaScript
- Responsive design
- No database/backend required
